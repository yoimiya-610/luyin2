# 录音随听 1.5.0

本次新增：录音室独立试音模式。波形、声谱图、音高、泛音和稳定性均来自实时麦克风 PCM；只使用独立内存缓冲，不创建音频文件、MediaStore 条目、编码器、预设或日期编号，不修改原长录音会话。支持随时停止、保留最后一屏、重新开始清空历史；离开录音室或切后台自动停止；旋转屏幕保留试音。试音与长录音互斥，包括长录音暂停状态。保留既有录音保存、导入、分类、播放、导出和钢琴功能。

验证范围：

- `scripts/test.ps1`：1,163 项断言/检查通过。包括来源分类 14 项、命名/长录音规则 33 项、波形与导出 1,038 项、格式/WAV 头 20 项、声学分析与钢琴合成 58 项。
- Android JVM 使用 Robolectric 4.14.1，覆盖 API 29 / 35；页面、分类删除、播放、导出、图谱与安卓兼容性原有 49 项。
- 新增 TrialMonitorTest：API 29 / 35 各 8 项，共 16 项。验证试音开始/停止/重启不写文件、会话、预设或编号；旧录音与队列不变；停止幂等；麦克风占用/错误释放；过期回调隔离；启动失败清理；真实内存采集构造器不创建文件/编码器、互斥与权限拒绝。采集构造器通过安卓音频 Shadow 验证，输入状态测试使用可控引擎，未使用真实麦克风。
- 新增 TrialUiTest 5 项：独立试音按钮、图谱切换、长录音互斥、离开页面/后台停止、旋转保留同一会话。
- WAV 写入测试替换 Robolectric 的 dup 行为，使用同文件的另一句柄；跨版本文件测试规范化 Windows 文件 URI；这些测试不验证 Android 原生文件句柄和真实编码器。

使用限制与尚未验证的项目：

没有连接红米 K80 或其他品牌手机，也未运行设备模拟器。未验证真实麦克风声谱图、旋转时硬件连续采集、锁屏/来电抢占、音频路由、实际耗电、钢琴发声和触控延迟、各格式系统编码器、GPU/系统字体、系统删除确认、安装升级或断电恢复。支持目标为各品牌 Android 10 及以上，不等于各品牌真机认证。试音退出或进程结束后不保存图谱；实时分析不支持旧录音离线分析或多音分离。
