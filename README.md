# 录音随听

把手机里的录音整理到一起，按自己选好的顺序连续播放。需要录音时，可以边录边分段；只是想听听、看看自己的声音，也可以打开试音，不留下录音文件。

支持 **Android 10 及以上**，不限红米或其他手机品牌。音频在本机处理，应用不上传录音。

**当前版本：1.5.4** · [下载安卓安装包](https://github.com/yoimiya-610/luyin2/raw/refs/heads/main/output/%E5%BD%95%E9%9F%B3%E9%9A%8F%E5%90%AC.apk)

## 安装后，从这里开始

下载 APK 后，在手机上打开安装文件，按系统提示允许这个来源安装应用。已经装过旧版的话，直接覆盖安装即可，不用先卸载。

底部有四个页面：

| 页面 | 可以做什么 |
| --- | --- |
| 录音库 | 查找、导入、分类、重命名和删除录音 |
| 录音室 | 试音、长录音、查看声音图表、弹奏钢琴 |
| 播放 | 调整播放顺序，选择顺序、乱序或单曲循环 |
| 预设 | 保存和再次使用一组录音的播放顺序 |

第一次使用时，按需要允许权限就好：试音和录音需要麦克风；扫描手机里的音频需要“音乐和音频”权限；允许通知后，可以更方便地在通知栏控制播放和长录音。

## 找到手机里的录音

打开 **录音库**，在右上角菜单选择 **扫描本地录音**。列表会区分本应用录制的“本机录音”、系统录音机录音、通话录音和其他音频，也可以按名称搜索。

如果有录音没有出现，可以试试这两种方式：

- 在录音库右上角选择 **授权录音文件夹**，选中存放录音的共享文件夹。
- 在手机自带录音机里选中录音，点击 **分享 → 录音随听**；也可以使用录音库的 **＋ 导入**。

有些手机会把系统录音放在私有目录，应用无法直接读取。遇到这种情况，用分享导入通常更方便。来源分类不准确时，可以在片段右侧菜单中选择 **修正录音来源**。

## 只想试试声音，不保存录音

进入 **录音室**，点击 **开始试音**。说话、唱歌或弹奏单音乐器，就能看到实时波形和声谱图，也可以查看音高、泛音和稳定性。

点击 **停止试音** 就会停止使用麦克风，最后一屏图表会留下，方便回看；再开始一次，会清空上次的试音图表。

试音不会生成音频文件、录音编号或预设。离开录音室、切到后台或锁屏时会自动停止，返回后需要自己重新开启；横竖屏旋转时则会继续试音。

试音和长录音不能同时进行。如果长录音正在录制或暂停，请先结束这次长录音，再开始试音。

## 录一段，也可以录很久

1. 在 **录音室** 选好录音格式，点击 **开始长录音**。
2. 需要歇一会儿或划分内容时，点击 **暂停并保存片段**，刚才这一段就会单独保存。
3. 点击 **继续录制下一段**，接着录。暂停的时间不会录进去，也不会计入录音时长。
4. 录完后点击 **结束并保存整组队列**。最后一段会保存，这次所有片段也会按录制顺序组成一份预设，方便以后连着听。

新录音默认按“日期-当天编号”命名，例如 `20261106-1`、`20261106-2`。同一天再录一次，编号会接着往下排；名称随时可以修改。

长录音可以在切换页面或熄屏后继续。离开录音室或锁屏后，会暂停看不到的声谱、音高分析和波形采样以减少计算；录音文件仍照常保存。返回录音室后图表会恢复，通常需要约 0.3 秒重新积累声音。录音没有设置总时长上限，实际能录多久取决于剩余空间、供电和手机的后台限制。单段接近 1 GB 时会自动分段，切换处可能有很短的间隔。

### 录音格式怎么选

开始前可在 **录音格式** 中选择，一次长录音保持同一种格式。

| 格式 | 适合的用途 | 每小时大约占用 |
| --- | --- | --- |
| M4A / AAC | 默认格式，日常说话、课堂或会议录音 | 58 MB |
| AAC | 需要独立 AAC 文件时 | 58 MB |
| AMR | 以节省空间为主的语音记录，音质较低 | 6 MB |
| WAV / PCM | 希望保留无损音频，便于后续处理 | 318 MB |

新录音通常保存在手机的 `Recordings/录音随听/` 文件夹；Android 10、11 使用 `Music/录音随听/`。

## 采样率与图表流畅度

M4A、AAC、WAV 录音及试音使用 44.1 kHz，AMR 使用 8 kHz。采样率决定采集音频的细密程度，与画面每秒刷新几次是两回事。1.5.3 将声谱图的分析与界面更新目标提升至每秒约 20 次，并复用历史图像，减少跳动。实际流畅度取决于手机性能与负载，尚需真机验证；刚开始分析时约需 0.3 秒积累声音。

## 看懂声音图表

在录音室点击 **波形 / 声谱图**，可以随时切换显示方式。

- **波形**：看声音随时间的强弱变化。说话时起伏，安静时接近平直。
- **声谱图**：横向看时间，纵向看频率，颜色表示声音在不同频率上的强弱。显示最近约 12 秒的声音，便于观察音高和泛音的变化。
- **音高轨迹**：看最近约 5 秒的音高走向。适合观察单个人声或单音乐器的持续音、滑音和颤音。
- **泛音分析**：H1 是基频，H2–H8 表示对应泛音的相对强弱。
- **声音稳定性**：查看最近约 5 秒的音高波动、非静音响度波动和有效音高占比。换音、颤音或渐强都会让数值变化，波动大不代表唱得不好。

在 **分析设置** 中，可以分别开关音高、泛音和稳定性分析。没有足够可靠的信号时会显示“—”，不必把每一个空白都当成异常。多人同时说话、和弦或较大的环境噪声会影响音高结果。

### 把音高坐标换成 A4、C5

在 **音高轨迹** 标题旁点击 **坐标**，选择 **科学音高记谱（A4 / C5）**，也可以切回 **频率（Hz）**。选择会记住，试音和长录音都适用。

这里的中央 C 是 C4，A4 对应 440 Hz，C5 约为 523.25 Hz。音名图里的淡线表示半音间隔，轨迹会保留实际音高的细微变化，方便看出偏高、偏低和滑音。

### 横过来，看得更清楚

点击录音室的 **横屏**，或开启手机自动旋转后横持手机，就能扩大图表。横屏时点击 **数据** 查看音高、泛音和稳定性，在这里也能切换音高坐标；点击 **竖屏** 可以切回去。

图表目前只用于实时试音和录音，暂不支持打开旧录音重新分析。它们只留在当前应用进程中，不会随音频一起保存。

## 用钢琴找个参考音

在录音室点击 **钢琴**，就可以弹奏内置键盘。支持多指和弦、滑键、切换八度和调节音量，A4 按 440 Hz 发声。

试音或录音时也能使用钢琴。不过，扬声器的声音会被麦克风一起收到；想减少串音时，可以戴上耳机。关闭键盘或切到后台后，钢琴会停止发声。

## 按自己的顺序听

在录音库中，按希望播放的先后顺序勾选录音，打开 **选项**，选择 **将所选加入队尾** 或 **用所选替换队列并播放**。

进入 **播放** 页面后，可以在每段录音的菜单里 **上移 / 下移**，也可以直接点击名称播放这一段。

播放模式有三种：

- **顺序播放**：按队列播放，最后一段结束后停止。
- **乱序播放**：随机切换录音，保存的原始队列顺序不会被打乱。
- **单曲循环**：反复播放当前这一段。

### 把常听的顺序存起来

在播放页选择 **管理队列 → 保存为预设**，或到预设页点击 **保存当前**，给这组顺序取个名字。下次打开 **预设**，就可以载入播放，也可以追加到当前队尾。

每次结束长录音，也会自动得到一份按录制顺序排列的预设。删除预设只删除这份播放顺序，不会删除音频。

## 分类、改名和删除

在录音库点击 **＋ 文件夹**，可以创建自己的分类，例如“练声”“课堂”“访谈”。本应用录音、系统录音和导入录音都能放在同一个分类里。

单段录音可从右侧菜单选择 **移动到文件夹**；多选后则在 **选项** 中一起移动、导出或删除。这里的文件夹是应用内分类，不改变手机上原文件的位置；删除分类也会保留录音。

**重命名** 可以选择真正修改文件名，或只修改应用里的显示名称。原文件只读时，选择“仅软件内名称”就好。

删除时请留意两种操作：

- **删除文件**：实际删除音频；导入录音会删除应用内的副本，系统文件可能需要手机弹窗确认。
- **仅移出软件**：保留原文件，只从应用列表、队列和预设中移出。之后可在录音库右上角选择 **恢复移出软件的录音**。

正在录制的片段不能删除。重要录音建议先导出备份，再删除文件。

## 导出和备份

点单段录音的菜单，选择 **导出录音**；多选时使用 **导出所选录音**。播放队列和预设也可以整组导出，录音室“本次录音片段”标题旁的导出按钮则用于导出这次已保存的片段。

接下来会打开手机的系统保存窗口，选择想放的位置即可：

- **只导出一段**：保存为原格式的音频文件。
- **一次导出多段**：保存为 ZIP 压缩包，里面的文件会加上 `001-`、`002-` 等顺序编号，解压后仍然容易按顺序找到。

导出不改变音频格式，也不会删除原文件。大文件导出期间请让应用继续运行，等提示完成后再关闭。

**卸载前请先备份。** 分享或文件导入的录音副本存放在应用内部，卸载会清除这些副本，以及应用内的分类、设置和预设。需要保留的重要录音，请先导出到自己选择的文件夹。

## 遇到问题时

**录音库里少了文件？** 先检查“音乐和音频”权限，再试试授权录音文件夹，或从系统录音机分享导入。系统未公开的私有目录无法直接扫描。

**锁屏后录音或播放停了？** 在手机的应用设置中允许后台运行，并关闭针对本应用的电池优化。红米 / HyperOS 通常可以在应用省电策略中选择“无限制”，其他品牌的菜单名称可能不同。

**试音或录音没有声音？** 检查麦克风权限、系统麦克风开关，以及是否被来电或其他应用占用。中断后请确认麦克风可用，再手动继续。

**切换录音时有空白？** 文件本身的头尾静音会保留，不同格式和手机的解码方式也可能影响衔接。

**应用意外关闭了？** 已经暂停保存的片段会独立保留，重开时会尝试恢复有效片段；当时还没正常保存的那一段可能无法恢复。

应用目前仍在完善，尚未完成红米 K80 或其他品牌的真机验证，实际音频表现和后台行为可能因手机而异。使用中也可以从页面右上角打开 **使用帮助**，或到 [Issues](https://github.com/yoimiya-610/luyin2/issues) 反馈遇到的问题。
