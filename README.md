# 录音随听

当前版本：**1.5.0**。可用新 APK 直接覆盖安装旧版本，保留原来的导入文件、播放队列和设置。

## 试音：只看声音，不保存文件

在 **录音室 → 开始试音** 中开启，仅申请麦克风权限。可自由切换波形与实时声谱图，并使用已有音高、泛音、稳定性分析和钢琴参考音。试音固定以 44.1 kHz 单声道 PCM 采样，显示最近约 12 秒的声音。

- 点击 **停止试音** 随时停止，释放麦克风，保留最后一屏图表；再次开始会清空试音历史。
- 试音不创建音频文件、编码器、MediaStore 条目、预设或日期编号，不写入已有长录音会话。图表只在内存中，关闭应用不会保存。
- 离开录音室、切到后台或锁屏时自动停止，不会在返回前台后自行重启。横竖屏旋转保留同一个试音会话，不重复打开麦克风；进程重启后不恢复试音。
- 试音和长录音互斥，包括长录音的暂停状态。请先结束长录音后试音，或先停止试音再开始长录音；长录音原有后台录制行为保留。
- 试音开始时暂停本应用播放器；麦克风权限被撤回、被其他应用占用或读取失败时停止。试音期间弹奏钢琴时，扬声器声音也会被麦克风采集。

## 安卓与品牌兼容性

本应用面向 **Android 10（API 29）及以上**，没有红米机型白名单，不依赖小米 SDK、账号或专有服务。红米 K80 是最初的使用场景，并非安装限制；其他品牌运行标准安卓的手机也在兼容目标内。安装包不限定 ARM 或 x86 架构。

“安卓通用”不表示支持所有历史安卓版本、所有硬件和所有系统定制：Android 9 及更早版本目前无法安装；不支持安卓 APK 的系统也不适用。当前 targetSdk 为 Android 15（API 35），它不是最高可安装系统版本，但未对所有更新系统和品牌进行验证。

- 录音、播放、钢琴、波形与声谱图使用安卓标准音频接口；实际可用编码器、麦克风参数、延迟和后台策略由设备决定。
- 系统媒体库缺少“文件所属应用”字段时自动改用基础扫描；字段顺序不同或来源信息缺失时仍可列出文件，不猜测来源。可在更多菜单手动修正来源，或授权录音文件夹。
- 任何品牌的系统录音机私有目录都可能无法直接读取。请使用系统分享导入、系统文件选择器导入或授权共享文件夹。
- 不同品牌可能需要在系统应用设置中允许后台运行、关闭本应用电池优化；菜单名称不统一。
- 自动兼容性检查覆盖 Android 10 与 Android 15 的页面启动、存储路径、媒体库降级及权限拒绝保留导入文件；属于 JVM 测试，**没有进行各品牌真机适配认证**。

1.4 加入实时声谱图、音高追踪、泛音和声音稳定性分析、横屏录音室，以及可以实际发声的复音钢琴。录音库来源按钮完整换行，去除按钮原生阴影与固定高度冲突造成的裁切观感。完整说明集中在各页面右上角的 **使用帮助** 中。

## 声谱图、音高与钢琴

- 在录音室点击 **波形 / 声谱图** 自由切换，选择自动保存。两种显示均来自录制时的真实麦克风 PCM，不使用预设动画。“声纹”在这里指声音波形，不做身份识别。
- 声谱图横轴为最近 12 秒的有效录音时间，纵轴为频率（常规格式 0–6 kHz，AMR 为 0–4 kHz），颜色为 −90 至 0 dBFS 的频谱幅度。开启音高追踪后叠加白色基频轨迹。未采集或分析来不及处理的区域保持空白，不插造数据。
- **分析设置** 可独立开关音高追踪、泛音分析、稳定性分析。全部关闭且选择波形时停止频谱分析，保留录音。分析在独立线程运行，队列有界，不阻塞录音保存。
- **音高追踪**：采用 YIN，范围 40–1,800 Hz，显示 Hz、十二平均律音名及相对最近音的音分偏差；A4=440 Hz。低于 −60 dBFS 或周期性置信度不足时显示“—”。适用于单个人声和单音乐器，不提供和弦分离，噪声、失真、混响和缺失基频会影响结果。
- **泛音分析**：H1 为基频，H2–H8 为对应整数倍频率附近的频谱峰值，显示相对 H1 的 dB；超出奈奎斯特频率或基频不可靠时留空。它不等同于乐器识别或音色评分。
- **声音稳定性**：最近同一连续片段 5 秒内的有效音高标准差（音分）、非静音帧（高于 −60 dBFS）的 RMS 电平标准差（dB）及有效音高占比；不足 8 个有效帧时相应波动留空。换音、颤音和渐强会自然增大波动，静音通过有效音高占比体现；不作医学诊断或“音质好坏”评分。
- **横屏**：点击录音室 **横屏**，或允许系统自动旋转后横持手机。横屏隐藏普通标题和底部导航，图表铺满可用宽度；**数据** 打开分析面板，**文件** 返回录音库，**竖屏** 恢复竖向。旋转只重建界面，前台录音服务继续工作。
- **钢琴**：录音室点 **钢琴** 打开内置双八度键盘，支持多指和弦、滑键、八度切换与音量调整；A4=440 Hz，16 声部，采用带泛音和衰减包络的本地合成音色，无需下载。关闭键盘、切换到后台或丢失音频焦点时停止发声。录音期间可作为参考音，手机扬声器的声音也会被麦克风录入；佩戴耳机可减少串音。

波形、声谱图与分析历史仅存于当前进程内，不写入音频文件，也不支持对旧录音进行离线分析。暂停冻结当前结果，继续时使用新片段计算稳定性；新会话清空历史。试音使用独立的分析与波形缓冲，不混入长录音数据。

## 文件夹、多选与删除

- 录音库的文件夹选择按钮支持切换 **全部文件夹 / 未分类 / 自建文件夹**；旁边的 **＋ 文件夹** 可创建分类。
- 同一个文件夹可同时收纳本应用录音、系统录音机录音和导入文件。这是软件内分类，不移动原文件，也不要求对外部文件拥有写入权限。
- 单个片段更多菜单 → **移动到文件夹**；勾选多段后 → **选项 → 移动所选到文件夹**。所选片段还可批量导出、删除、加入队列，以及按当前筛选全选。
- 录音库右上角 → **管理文件夹** 可重命名或删除分类；删除文件夹后，其成员回到未分类，音频文件保留。
- 片段更多菜单 → **删除录音**，或多选 → **删除所选录音**，有两种处理方式：**删除文件** 会实际删除音频，导入文件只删除本软件的副本，系统录音需要 Android 确认；**仅移出软件** 会保留文件并从列表、队列和预设中移出。
- 右上角 **恢复移出软件的录音** 可恢复未被实际删除的音频显示；已清理的队列和分类不会自动恢复。
- 录制中的当前片段不能删除；已保存片段可删除，结束长录音时不会重新加入预设。正在导出时需等待完成后再删除。

## 录音格式与播放模式

在 **录音室 → 录音格式** 中选择格式，选择会保留到下次启动；一次长录音保持相同格式，需结束后才能切换。

| 格式 | 编码与采样 | 典型空间占用 |
| --- | --- | --- |
| M4A / AAC | AAC、44.1 kHz、单声道、128 kbps | 约 58 MB/小时 |
| AAC | ADTS 容器、AAC、44.1 kHz、单声道、128 kbps | 约 58 MB/小时 |
| AMR | AMR-NB、8 kHz、单声道、12.2 kbps | 约 6 MB/小时 |
| WAV / PCM | 无损 PCM16、44.1 kHz、单声道 | 约 318 MB/小时 |

文件扩展名、实际编码和媒体类型保持对应，不通过改后缀伪装格式。默认软件内名称仍为日期编号，实际文件使用 `.m4a` / `.aac` / `.amr` / `.wav`。

在 **播放页 → 播放模式按钮**，或 **管理队列 → 播放模式** 中选择 **顺序播放 / 乱序播放 / 单曲循环**。乱序使用 Media3 的播放顺序管理，不打乱已保存的队列或预设列表；模式会在重启后恢复。

## 页面与功能分类

界面采用浅色背景、森林绿录音面板、统一线条图标和卡片样式。底部导航固定为四个独立页面，避免在首页堆积全部按钮。

| 页面 | 主要功能 | 次要操作的位置 |
| --- | --- | --- |
| 录音库 | 搜索、来源与文件夹筛选、多选、导入 | 更多菜单：移动分类、导出、重命名、删除、修正来源；右上角管理文件夹与授权 |
| 录音室 | 试音、格式选择、长录音、波形/声谱图、暂停和继续、结束保存整组 | 分析设置、钢琴、横屏、本次片段列表及整组导出 |
| 播放 | 进度、上一段/下一段、顺序/乱序/单曲循环、队列 | “管理队列”保存预设或批量导出；片段菜单上下移动或移出 |
| 预设 | 查看和载入已经保存的播放顺序 | 预设更多菜单：追加、导出整组、重命名、删除 |

录音库和预设页保留紧凑的迷你播放器。录音室专注录制，不堆叠播放控件。列表使用原生 ListView，只创建可见行，适合较多录音。

## 录音导出

- **单个片段**：点片段右侧更多菜单 → 导出录音 → 在系统保存窗口中选择位置。按原音频格式复制，不转码。
- **所选片段**：按希望的先后顺序勾选 → 选项 → 导出所选录音。
- **播放队列**：播放页 → 管理队列 → 导出整个队列。
- **整组预设**：预设页 → 选中预设 → 导出整组录音。
- **本次长录音**：录音室 → 本次录音片段标题旁导出图标，只导出已经保存的片段。

一次导出一段时生成独立音频；多段时生成 ZIP 文件，里面按 `001-原名称.m4a`、`002-原名称.m4a` 等顺序编号。重复加入队列的片段会按出现次数分别导出；超过 999 段时会增加编号位数，仍可按文件名排序。各段保持原始字节和音频格式，原文件不会被删除。

导出前通过 Android 的 `ACTION_CREATE_DOCUMENT` 系统窗口选择保存位置，不额外申请整个存储盘的管理权限。取消保存不会开始复制。如果读取权限失效、原文件已移动或磁盘空间不足，会报告失败并尝试清理不完整文件；此时原始录音保留。导出时顶部显示状态提示，仍可切换页面和控制录音；旋转屏幕不会重复启动导出。大文件导出期间请保持应用运行，进程被强制结束可能留下不完整的导出文件，下次打开时会提示重新导出。

## 长录音、预设队列与重命名

### 长录音

1. 底部切换到 **录音室 → 开始长录音**，允许麦克风权限。建议允许通知，以使用通知栏里的暂停、继续和结束按钮。
2. 点击 **暂停并保存片段**，会立刻关闭并保存这一段音频；暂停期间不录制，也不计入录音时长。
3. 点击 **继续录制下一段**，开始下一段；可以反复暂停、继续。
4. 点击 **结束并保存整组队列**，正在录制的最后一段也会保存，本次全部有效片段会按录制顺序自动保存成一个预设队列。不会覆盖原来的播放队列。
5. 底部切换到 **预设**，选择本次长录音，载入或直接播放。也可重命名这个预设。

所有格式共用一个 `AudioRecord` 采集 PCM16，同时送入保存与分析，避免两个麦克风客户端互相抢占。M4A/AAC/AMR 使用系统 `MediaCodec` 编码，M4A 使用 `MediaMuxer` 封装；AAC 为 ADTS，AMR 为 AMR-NB 文件，WAV 写入 PCM16 RIFF。波形使用同一 PCM 的真实峰值，每 100 ms 更新，显示最近约 12 秒的有效录音振幅包络。暂停时冻结，继续时追加；新会话清空。分析先抗混叠降采样，再进行 Hann 窗 STFT 和 YIN，约每秒 10 帧；分析分辨率和频段不改变保存文件的采样率。

新录音单独显示为 **本机录音**。Android 12 及以上的实际文件保存到共享目录 `Recordings/录音随听/`，默认格式为 M4A，也可按上述选项选择其他格式。Android 10/11 的兼容目录为 `Music/录音随听/`。

默认软件内名称为 **手机本地日期-当天递增数字**，例如 `20261106-1`、`20261106-2`；实际文件使用所选格式的扩展名。当天不同格式、不同长录音共用递增编号，跨日的新片段使用新日期。极短、失败的录音不会生成有效片段，已使用的编号不回退，因此可能出现跳号。

录音使用带麦克风类型的前台服务，并在录制期间保持唤醒锁，支持熄屏及返回首页后继续录制。长录音没有设置总时长上限，但受手机储存空间、供电及系统策略影响；单段接近 1 GiB 时自动分段后继续。自动分段可能存在很短的切换间隔。如麦克风被来电或其他应用占用，会尝试保存当前段并暂停，须确认后继续。

录制开始和继续时会暂停本应用播放器，避免将扬声器声音录入；在软件内播放前应先暂停录音。

每个已完成片段及会话状态会写入本地索引。若应用进程意外结束，下次打开会尝试恢复有效片段并生成预设。**尚未正常关闭的当前片段可能无法恢复**；已保存的其他片段会独立保留。此恢复逻辑尚未经过 K80 真机断电测试。

### 预设队列

- 播放页 **管理队列 → 保存为预设**，或预设页 **保存当前**：将当前播放队列按原顺序保存为一个命名预设。
- 底部 **预设**：可载入、载入并播放、追加到当前队尾、导出整组、重命名或删除预设。
- 载入后可上下移动片段，再保存为新的预设。删除预设只移除列表，不删除音频文件。
- 每次正常结束长录音都会自动保存一个独立预设；没有有效片段时不创建空预设。异常恢复重复执行时使用相同的会话标识，不重复创建预设。

### 重命名

录音库中点击录音后选择 **重命名**，或长按名称；播放队列中也可长按名称重命名。重命名会同步软件内当前队列及已保存预设中的引用。

- **修改文件名**：真正修改原文件，保留原扩展名。本应用新录制和导入的文件可直接修改；来自其他应用的媒体文件可能需要系统确认写入授权。
- **仅软件内名称**：修改本软件的显示名称，不改动原文件，适用于只读目录或不支持重命名的文件提供方。
- 如果旧的文件夹授权只有读取权限，可重新通过 **授权文件夹** 申请读写权限；若系统仍不允许，可使用软件内名称。

用于本地录音整理与连续播放的原生 Android 应用，面向各品牌 Android 10 及以上设备。目标 Android 15，不申请 INTERNET 联网权限，不上传音频。

## 安装使用

安装包：`output/录音随听.apk`。这是本地调试签名版本，可传到手机后点击安装，按系统提示允许该来源安装应用。

1. 打开“录音随听”，在录音库右上角选项选择 **扫描本地录音**，允许“音乐和音频”权限。后续每次进入应用自动重新扫描。
2. 录音库按 **本机录音 / 录音机 / 通话录音 / 其他音频** 区分。来源依据目录和 MediaStore 的所属应用判断；无法确认的音频放入“其他音频”。片段更多菜单可手动修正来源。
3. 按要听的先后顺序勾选文件，点击 **选项 → 将所选加入队尾** 或 **用所选替换队列并播放**。
4. 在播放队列片段的更多菜单中用 **上移 / 下移** 调整顺序，点击名称立即播放该段，支持从队列移除，不删除原文件。
5. 播放器的 **顺序播放** 按钮可切换成 **单曲循环**。顺序模式播完最后一首停止；循环模式重复当前一首。支持进度拖动、上一首、下一首、通知栏与锁屏控制。

### 各品牌录音访问与后台限制

自动扫描范围是 Android 系统媒体库中本应用可读取的音频，不能保证无授权读取手机上的每一个文件。

- 共享录音文件夹（例如 `MIUI/sound_recorder`）：可自动识别，也可用 **授权文件夹** 补充扫描。授权时指定录音来源，下次扫描会记住。
- 通话录音目录（例如 `MIUI/sound_recorder/call_rec`）：单独归类，优先于普通录音机分类。
- `Recordings/` 是通用目录，不能仅凭该名称断定是小米录音机产生的文件。
- 录音机私有目录，如 `Android/data/com.android.soundrecorder/files`：受 Android 限制，普通第三方应用无法直接读取，也不能通过常规文件夹授权绕过。请在系统录音机选中录音 → 分享 → **录音随听**；或先导出到共享文件夹，再授权该文件夹。
- 文件导入和分享导入均会复制到本应用内部存储，使用 SHA-256 避免重复保存相同内容。卸载应用会删除这些副本，原始录音不会被更改。

如果长时间锁屏后播放或录音被系统终止，请在系统设置允许本应用后台运行并关闭针对本应用的电池优化；红米 / HyperOS 可在应用省电策略中选择“无限制”。不同品牌和系统版本的菜单名称可能不同。

连续播放使用 Media3 ExoPlayer 同一个播放队列自动切换，无需逐首点击。文件自带的头尾静音会保留；不同文件格式、编码器延迟及设备解码器可能影响衔接，尚未在 K80 实机验证逐采样无缝效果。

## 验收建议

- 开启试音，对麦克风说话或弹琴，切换波形/声谱图及横屏；随时停止后确认图表冻结、麦克风指示消失。再次开始确认历史清空。检查录音库、预设、录音目录和当天编号均未变化。
- 试音时切换到录音库、切后台及锁屏，确认停止；横竖旋转确认持续且没有第二个麦克风客户端。拒绝权限及其他应用抢占麦克风时检查提示。先结束长录音再试音，停止试音后录制多段并核对原有保存流程。
- 在红米 K80 上播放或发出持续 A4/440 Hz，检查四种格式下的图谱与基频；静音、噪声、换音、颤音、强二次谐波时核对结果与留空行为。
- 录制中切换波形/声谱图、关闭再开启分析、横竖旋转、展开数据、弹奏钢琴，确认录音持续且暂停保存片段、预设顺序不变。检查横屏刘海/打孔与手势区域。
- 用双指弹和弦、滑键、改变八度和音量，检查音符与 Hz、触控延迟、松键衰减、关窗/后台/焦点抢占后无持续音。钢琴音色为合成音，不是原声钢琴采样。
- 检查底部导航文字在系统自定义字体和放大字号下居中、基线一致；确认所有页面只保留功能标签和必要状态。
- 创建两个文件夹，把本机、系统和导入录音混合多选移动；重命名文件夹、重命名文件后确认分类不丢失；删除分类后音频仍在。
- 分别测试仅移出软件、恢复显示、删除本机文件、删除导入副本、系统删除授权允许与取消；确认队列和预设中不再出现已删除片段。
- 分别录制 M4A、AAC、AMR、WAV，暂停继续后结束，检查真实扩展名和编码、时长、实际播放及导出。
- 切换乱序播放，检查所有条目可遍历，保存的原列表顺序不变，重启后模式仍保留。

- 在 K80 上切换四个页面，检查功能分类、字体放大、横屏和软键盘收起后的布局；确认长录音不会因页面切换而停止。
- 录音室对麦克风说话后保持安静，检查波形随实际音量变化；暂停时冻结，继续时追加，开始新录音时清空。
- 分别导出一段录音、多个勾选片段、含重复项的播放队列和整组预设，核对音频可播放、ZIP 中顺序与原字节一致。
- 取消系统保存窗口、撤回源文件权限、模拟空间不足，检查错误提示和原文件保留。

- 连续录制三段，每段 5 秒以上，中间暂停；确认暂停后立即可见独立录音，结束后自动出现顺序正确的预设，软件内默认名为日期编号。
- 在同一天开启第二次长录音，确认编号继续递增；跨日新段确认使用新日期。
- 在录制中、暂停中分别结束会话；测试短于 1 秒的片段、拒绝麦克风权限、关闭系统麦克风开关及空间不足。
- 熄屏录制、从最近任务列表划走应用、通知栏暂停/继续/结束；检查录制时长不包含暂停时间。
- 保存两个不同的手动预设，重开应用后分别载入；重命名录音后检查所有预设仍可播放，重命名预设后检查标题持久保存。
- 在已保存多段后终止应用进程，重开检查已完成片段与预设恢复；对未完成的当前段不作可恢复保证。

- K80 上分别准备录音机录音、通话录音和普通音乐，核对分类；核对未索引文件、分享导入和文件夹授权。
- 选 A、C、B 三段录音，检查队列为 A→C→B；移动顺序、删除当前项及重复加入同一项后继续播放。
- 播放两段短录音，确认自动切换且最后停止；打开单曲循环，确认当前段重复。
- 锁屏十分钟、切换应用、耳机拔出、来电与音频焦点抢占，检查后台与暂停行为。
- 关闭再打开应用，确认队列、循环设置和播放位置恢复；原文件被删除或权限撤回时检查提示。

目前的自动检查不能替代实机测试，尤其是 HyperOS 私有目录、后台省电策略和文件编码差异。
